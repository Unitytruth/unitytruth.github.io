# Unity Hidden Truth Ministry Website

This static website is designed for GitHub Pages.

## Files
- `index.html` — ministry homepage and existing content
- `institute.html` — standalone Unity Hidden Truth Institute dashboard
- `lessons-in-truth.html` — standalone course outline
- `institute-courses.html`, `personal-development.html`, `attitude-character.html`, `zero-anger.html`, `anger-awareness.html`, `attributes-of-god.html`, `governance-resources.html` — standalone learning-area pages
- `logo.png` — ministry emblem
- `script.js`, `styles.css` — existing project assets

## Publish
Upload the individual files and `logo.png` to the root of the `main` branch of `Unitytruth/unitytruth.github.io`. GitHub Pages does not publish a ZIP archive as a website; extract it and upload the files.

Some course descriptions are introductory outlines, not complete lesson manuscripts or a student-management system. Contact and enrolment links lead to the existing website contact area.

- `daily-inner-journey.html` — standalone devotional-series landing page
- `think-about-this.html` — standalone daily-reflection landing page
- `resource-centre.html` — four-category book directory only

Dashboard note: source-document destinations should be replaced with actual approved file links when those source documents are provided. The new series pages are organised landing pages, not claims that the full daily archive is already uploaded.

## Publish safely
1. Keep a backup of the current GitHub repository before replacing files.
2. Extract this ZIP on your computer.
3. Upload the extracted files to the repository root on the `main` branch, preserving the filenames and folder placement.
4. Review the GitHub change list before committing. Do not delete files that are already in the repository unless you have confirmed they are obsolete.
5. After GitHub Pages finishes deploying, open the website and hard-refresh the page.
